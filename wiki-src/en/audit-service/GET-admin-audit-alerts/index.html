GET /admin/audit/alerts

分页查询告警记录，支持按类型、严重程度、状态、租户筛选。参考：ISO 27001:2022 Annex A.12.4 (Event Logging)、PCI DSS v4.0 Req 10 (Log & Monitor)。

审计服务 `bearerAuth` application/json

Request Parameters

NameInTypeRequiredDefaultExampleConstraintsDescription
type query string No 告警类型
severity query string No 严重程度: low/medium/high/critical
status query string No 状态: open/acknowledged/escalated/resolved/dismissed
page query integer No 1 页码（默认1）
page_size query integer No 20 每页条数（默认20）
